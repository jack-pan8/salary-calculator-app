# 月薪收入计算器 - 每秒收入计算应用

这是一个炫酷的月薪收入计算器应用，可以帮助您计算每一秒钟您能赚多少钱！应用采用金色主题设计，包含流畅的动画效果和金币跳动声音。

## 功能特点

- **实时计算**：输入月薪后，自动计算每日、每小时、每分钟和每秒的收入
- **炫酷动画**：当每秒收入的整数部分不足10元时，会触发金币跳动动画
- **声音效果**：金币跳动时伴随清脆的声音效果
- **金色主题**：采用金色字体和渐变背景，营造高端视觉体验
- **响应式设计**：适配各种屏幕尺寸的设备（手机、平板、桌面）

## 如何使用

1. 在输入框中输入您的月薪金额（元）
2. 点击"计算"按钮或按下Enter键
3. 查看计算结果，包括每月、每日、每小时、每分钟和每秒的收入
4. 当每秒收入的整数部分不足10元时，观察金币跳动动画

## 技术实现

- **HTML5**：构建页面结构
- **CSS3**：实现金色主题和动画效果
- **JavaScript**：处理计算逻辑和交互效果
- **Audio API**：播放金币声音效果

## 添加声音效果

要启用金币跳动的声音效果，请按照 `sound_instructions.txt` 文件中的说明添加 `coin_sound.mp3` 文件。

## 运行方法

### 方法1：直接打开HTML文件
1. 找到 `salary_calculator` 文件夹
2. 双击打开 `index.html` 文件
3. 应用将在您的默认浏览器中运行

### 方法2：使用Web服务器
如果您有安装Python，可以使用项目根目录下的 `start_server.py` 脚本：
1. 打开命令提示符
2. 导航到应用根目录: `cd 路径\ProgrammingLearningApp`
3. 运行: `python start_server.py`
4. 在浏览器中访问: `http://localhost:8000/salary_calculator`

## 注意事项

- 为了获得最佳体验，建议使用现代浏览器（Chrome、Firefox、Edge等）
- 声音效果可能受到浏览器自动播放策略的限制，首次使用时可能需要点击页面以启用声音
- 所有计算基于每月工作22天，每天工作8小时的标准计算
